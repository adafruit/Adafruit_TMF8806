# Adafruit TMF8806 [![Build Status](https://github.com/adafruit/Adafruit_TMF8806/workflows/Arduino%20Library%20CI/badge.svg)](https://github.com/adafruit/Adafruit_TMF8806/actions)[![Documentation](https://github.com/adafruit/ci-arduino/blob/master/assets/doxygen_badge.svg)](https://adafruit.github.io/Adafruit_TMF8806/html/index.html)

Arduino library for the ams OSRAM TMF8806 direct Time-of-Flight sensor. The
sensor ranges to 5m with its built-in ROM firmware. This library also includes
the optional ams OSRAM RAM firmware patch required for 10m mode.
